- **LiteRT-LM Android 0.18.1**, `com.google.ai.edge.litertlm:litertlm-android`. Upstream: https://github.com/google-ai-edge/LiteRT-LM. The LICENSE and THIRD_PARTY_NOTICE from the resolved 0.18.1 AAR are copied to app/src/main/assets/licenses. Retain the license/notice metadata supplied by this artifact and its transitive dependencies; complete the redistribution review before public release.
- **stable-diffusion.cpp**, commit `290148d2e31ca6ef9757d567905776b5f3646db5`. Upstream: https://github.com/leejet/stable-diffusion.cpp. Source license files are retained in the fetched dependency; the native runtime notices are included under APK assets/licenses.
- **GGML**, commit `d49c49e1dd361ba3c0a77c90b5b1404b83969aa8`. Upstream: https://github.com/leejet/ggml. Retain its upstream license and bundled notices.
- **Gson** is currently supplied transitively by the LiteRT-LM dependency and used for metadata/conversation serialization. Its license and exact resolved version must be included in the final dependency inventory.
- **Gradle wrapper / Android build tools / Kotlin** are build dependencies with their respective upstream terms.

No Cactus code/runtime is incorporated. No model weights are bundled in the source tree or APK. Users download weights under each model publisher's separate license/access conditions. A LoRA license does not replace its base model's license.

- **Underdog Woof runtime**, ConwayResearch/Underdog-Woof revision `be702960539777fc3f698e54335276a8391b00f9`, under the **Underdog Non-Commercial License 1.0**. The original Python runtime/normalizer/lexicon are bundled under `app/src/main/python/underdog_woof`; its LICENSE, NOTICE and origin/change record are retained there and the license/notice are included in APK assets/licenses. RunLocal adds cooperative cancellation hooks. The weights are downloaded separately from the same pinned revision with publisher SHA-256 verification. The Woof runtime is not relicensed as Apache-2.0. Non-commercial use requires visible "Voice by Underdog Woof" linked to https://underdog.ai; published audio must credit Underdog Woof, and commercial use needs separate written permission. The upstream NOTICE attributes Mimi, LibriTTS-R and Emilia-YODAS under CC-BY 4.0.
- **Chaquopy 17.2.0**, https://github.com/chaquo/chaquopy, MIT; LICENSE.txt is included in APK assets/licenses. Embeds CPython 3.13 in the speech process only; CPython LICENSE is included in APK assets/licenses.
- **NumPy 1.26.2** Android Python 3.13 wheels from Chaquopy's index, BSD-3-Clause with bundled native dependencies including OpenBLAS. NumPy's upstream license is included in APK assets/licenses and wheel distribution metadata is retained in Python requirements assets. CPython and native wheel notices remain separately licensed and must be included in the final redistribution audit. The packaged Python ELF files are included in 16 KB alignment verification.

Install the APK

  1. On an Android 12+ ARM64 phone, download the signed ARM64 APK from GitHub Releases.
  2. Open the download and follow Android’s installation prompt. Android may ask you to allow installs from the browser or file manager you used.
  3. Open Models → Add model, install a model, and select it at the top of Chat.

To keep chats and models, install updates over RunLocal. If Android refuses the update, check that the APK is newer and uses the same signing certificate as your installed build.

Models and memory

Use compatible .litertlm text containers and complete Stable Diffusion 1.x checkpoints. Supported LoRAs require their matching base. Model weights download separately, and a compatible format can still exceed your phone’s RAM.

If a model fails to load, try a smaller build. If a text model reports a GPU error, choose CPU under Chat → ＋ → CPU / GPU processing and retry. See the compatibility guide for experimental models and unsupported formats.

Offline voice

Android dictation and read-aloud depend on the on-device recognizer and offline voice packs available on your phone. In Chat, the microphone dictates and the speaker reads a text reply aloud.

For experimental Juno and Mira voices, open Models → Add model → Supported voice models, download Woof, and choose a voice in Chat. Voice by Underdog Woof. Woof has a separate non-commercial license.

App updates

On rc8 or later, open Chat → ☰ → App updates. Enable Include release candidates (experimental) to see prereleases, then tap Check now. You’ll see an update when a newer build is published in your selected channel.

Rc7 and earlier need one manual install of rc8 or later to discover candidates. Android asks you to approve each APK install.

Report a problem

Search or open a GitHub issue. Include your RunLocal version, Android version, phone model, and steps to reproduce. For model issues, add the public model link or format and CPU/GPU selection. Remove private prompts, images, and file paths from anything you include.

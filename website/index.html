Text

Stream chat replies from .litertlm models. Choose CPU or GPU per model.

Image
Stable Diffusion 1.x

Generate from a prompt or starting image on the CPU.

Voice
Android speech and Underdog Woof

Dictate with on-device recognition or read replies with an installed offline voice. Juno and Mira are experimental. Voice by Underdog Woof.

Full installation instructions
  1. Install RunLocal.

    Open the signed APK and follow Android’s installation prompt.

  2. Add a model.

    In Models, tap Add model. Paste a supported public Hugging Face link or import a file.

  3. Choose it in Chat.

    Pick the installed model at the top of Chat and send a message.

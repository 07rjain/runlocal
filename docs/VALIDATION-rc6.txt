RunLocal 1.0.0-rc6 · versionCode 12 · standalone ARM64 · Android 12+

Scope
-----
General speech model catalogue, shared setup/selection/testing/playback and
runtime-adapter interface. The first supported downloaded family is Underdog
Woof, with English Juno and Mira voices. Other model families need a compatible
adapter and reviewed recipe; arbitrary voice weights are not executable.

The UI retains exactly Chat and Models. Models contains speech downloads,
voice tests and removal. Composer tools choose a voice, read draft text or stop
speech; completed text replies use the selected voice. Android offline voices
and on-device recognition remain available. Woof inference runs serially in a
separate :speech process with cancellation, audio focus and foreground-only
playback. No cloud inference or prompt/audio upload was added.

Limits and phone acceptance
---------------------------
The device tool could not boot Pocket_API_35. Its suggested emulator command was
tried once and failed with: "x86_64 emulation currently requires hardware
acceleration" / "KVM requires a CPU that supports vmx or svm". No working Android
emulator or physical phone was available. Startup/UI, NumPy/Chaquopy inference
on Android, audio playback/focus, background cancellation, download resume,
low-memory/process-death behavior and thermal/performance remain UNVERIFIED on
Android. Host timings are not phone benchmarks. Text/image inference was not
rerun with multi-GB models. This candidate is experimental, not stable v1.

Phone steps: docs/SPEECH-MODELS.md. Install over the existing app, download Woof
in Models, test both voices, repeat in airplane mode, then test reply/draft
reading, cancellation, restart selection and model removal. Record the phone
model, Android version, measured speech timings and any exact error.

The rc5 startup-permission investigation remains in docs/VALIDATION-rc5.txt.

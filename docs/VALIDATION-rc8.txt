Behavior
--------
Stable releases remain the default. History -> App updates has an explicit
Include release candidates (experimental) checkbox. Candidate checks read the
most recent 30 public GitHub releases and choose the highest validated version
code. Drafts, malformed entries, foreign URLs, missing ARM64 assets, ambiguous
version markers and installed/older versions are excluded. Candidate notices
are labeled experimental. Channel changes clear cached availability and notices;
an in-flight result from a different channel is discarded. No chats, model
files or device identifiers are sent. APK installation still needs user action.

Rc7 and older cannot discover prereleases. Install rc8 once over the existing
app without uninstalling, then enable candidate updates for future versions.
Exactly Chat and Models remain. No inference/runtime changes in this version.
The release workflow checksum now lists only the APK actually uploaded.

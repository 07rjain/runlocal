UI and behavior
---------------
Exactly Chat and Models remain in bottom navigation.

Models is one installed-model library, with All / Text / Voice / Image filters,
a single Add model action, Use in Chat and per-model management menus. URL setup,
supported voice downloads and local imports open in an Add model panel. Saved
locations/discovered files and image components open on demand. The former
always-visible voice-testing form and stacked setup/library sections are gone.
Text and voice models can be removed from their menus; image models expose their
component files for individual removal with confirmation and a shared-file warning.

Chat's shared picker lists installed text models, configured image profiles and
each supported installed voice. Choose Woof Juno/Mira, type in the normal message
bar, then press play. The text is saved in the conversation; a reply offers Play
again and Text. Replay synthesizes again; temporary audio is not a permanent
attachment. Text replies keep a speaker action, and microphone dictation remains
available in the same composer. CPU/GPU is explicit in message tools and the
current selection appears in the header. Woof credit remains visibly linked once
in the composer instead of repeated below every reply.

The native text engine is closed on its owning serial worker before downloaded
speech starts. A launch fence cancels delayed startup after stop/backgrounding.
Speech reply completion remains attached to its originating chat. Existing JSON
fields/model keys, app ID, files and history are preserved. New voice chats use
speech:<model-id>:<voice-id> keys; missing voices/models do not silently substitute.
